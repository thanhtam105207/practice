# ⭐ Host Studio — host thêm nội dung, người học thấy ngay

## Cài 1 lần
1. Supabase → SQL Editor → chạy `supabase-content.sql` (sau schema và host.sql đã chạy trước đó).
2. Đẩy toàn bộ thư mục lên GitHub Pages như cũ.

## Host dùng
Đăng nhập tài khoản host → bấm nút ⭐ (góc phải, trên thanh dưới) → **➕ Thêm nội dung**.
Chọn môn (English/中文/日本語) + loại:
- **Từ vựng**: mỗi dòng một từ, ngăn bằng `|`. Vào thẳng mục từ vựng của môn đó (ja: nhóm "⭐ Host"; zh: bài "⭐"; en: Unit bạn nhập ở ô Nhóm).
- **Bài tập**: mỗi dòng một câu — `p:` điền trợ từ `{は}` · `t:` gõ đáp án `hỏi => đáp1 / đáp2` · `c:` trắc nghiệm `hỏi => ĐÚNG ; sai ; sai` · `r:` sắp xếp `a / b / c` · `f:` tự viết `hỏi => câu mẫu`.
- **Ghi chú / thông báo**, **Ảnh / file** (tải lên hoặc dán link; ảnh, mp3, PDF đều được), **Tùy ý (JSON)**.
Bấm 🗑 trên mỗi mục để xóa cho tất cả mọi người.

## Người học
Mở app là tự tải; đang mở thì nhận ngay qua Realtime (có toast "✨ Host vừa thêm…" và số đỏ trên nút ⭐). Có lưu offline.
Từ trùng với từ đã có trong tài khoản người học sẽ không hiện lại.
